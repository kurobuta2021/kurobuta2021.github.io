# 黑豚君 · 日本旅行工具箱 MVP

这是一个面向中国游客的移动端旅行工具门户。厕所功能使用 OpenStreetMap 的日本全国点位并按当前位置查询；吸烟点暂时筛选成熟第三方服务。产品补充中文说明、地图导航、本机收藏和日文沟通卡。

## 当前可用功能

- 顶部语言选择：支持简体中文、繁體中文和 English，并在当前浏览器记住上次选择。
- “随便O”：浏览器定位当前位置，在页面内显示周围 3 公里的 OpenStreetMap 厕所点位，按距离排序，并支持 Google／高德导航及本机收藏。
- “来一根”：跳转 CLUB JT 和吸烟区信息共享地图君，并显示 20+ 提醒。
- 黑豚君导航助手：粘贴地点名称、地址、坐标或带坐标的分享链接，打开 Google、高德或 Apple 地图。
- “豚一下”：地点收藏在当前浏览器，不需要登录。
- “给日本人看”：厕所、吸烟点和地图指路三类大字日文卡，支持复制和设备语音播放。
- “找黑豚”：填写包车／接送机、定制行程、餐厅预约等需求，通过系统分享菜单发送；没有后端，也不收款。
- 城市切换：记录东京、大阪、京都、北海道或冲绳偏好；当前内容以全国服务和东京服务为主。

动漫原景地、行李寄存、温泉和紧急帮助入口暂时显示“正在整理”，避免在未核实前放入不可靠链接。

## 数据与隐私

- 收藏使用浏览器 `localStorage`，只保存在当前设备。
- 咨询内容不会上传服务器；用户主动点击后，由设备分享菜单或剪贴板处理。
- 页面不包含账号、短信、邮箱登录、付款或用户照片上传。
- 第三方地点和服务由对应网站提供，使用时以现场信息及第三方条款为准。

## 本地预览

直接双击 `index.html` 即可打开。为保证剪贴板、分享和本地资源表现一致，建议使用本地网页服务：

```bash
python3 -m http.server 4173 --directory .
```

然后访问 `http://127.0.0.1:4173/`。

## 发布

网页由静态 HTML、CSS、JavaScript 和一张本地图片组成，可以放在任何静态托管服务。发布到 GitHub Pages 时，将本目录文件放到仓库根目录，并在 `Settings → Pages` 里选择从 `main` 分支发布。

如果以后加入大量商业交易、登录、订单或付款，应改用适合商业应用的托管和后端服务。

## 需要上线前补充

- 用户本人的微信号或其他联系方式。
- 真实微信二维码。
- 隐私政策、运营主体和联系信息。
- 如开始撮合包车、接送机或收取佣金，需要核实合作方运输资质和自身旅行相关业务边界。
